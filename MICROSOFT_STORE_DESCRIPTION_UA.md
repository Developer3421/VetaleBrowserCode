## Короткий опис (Short description)
Сміливий браузер для Windows з **локальним AI (Gemma 3)**, глибокою кастомізацією UI, Vetale Search з відповідями Perplexity та суворим підходом **«лише локально»**.

---

## Повний опис (Full description)
Ласкаво просимо до **Vetale Browser** — сучасного браузера для Windows для тих, хто хоче, щоб веб був *персональним*, *потужним* і *приватним*.

Це не просто вкладки та пошук. Vetale Browser поєднує:
- **AI на вашому пристрої** (Gemma 3) для щоденного браузингу, письма й навчання
- Інтерфейс, який можна **перебудувати під себе** (кольори, розміри, відступи)
- Розумніший пошук: **Vetale Search** + опційні відповіді з **безкоштовного досвіду Perplexity AI**
- Більш приватний пошук медіа через **ваші власні API-ключі** (Unsplash / Pexels / YouTube)
- Сувору обіцянку: **жодні дані не надсилаються розробнику** — усе залишається на вашому пристрої
- Віконну систему для великих робочих наборів: **overflow-вікна**, **необмежені вкладки** та **перетягування вкладок між вікнами**

### Локальний AI, який залишається на вашому ПК (Gemma 3)
Vetale Browser має AI-помічника, розрахованого на **локальну** роботу з **вбудованою моделлю Gemma 3** (коли модель доступна на вашому пристрої).

Використовуйте для:
- Підсумків статей і довгих сторінок
- Перефразування тексту (ясніше, коротше, професійніше)
- Пояснення понять (від простих до технічних)
- Генерації ідей та планів
- Чернеток повідомлень/нотаток під час перегляду

### Vetale Search: звичайний пошук + розумні відповіді
У Vetale Browser є **Vetale Search**:
- Введіть звичайний запит і отримайте класичні текстові результати.
- Опційно вмикайте режим відповіді/пояснення, що працює на **безкоштовному досвіді Perplexity AI** (залежить від доступності/налаштувань).

### Більш приватний пошук зображень і відео (ваші ключі)
Для пошуку зображень і відео Vetale Browser може використовувати **ваші власні API-ключі**:
- **Unsplash** — пошук зображень
- **Pexels** — пошук зображень і відео
- **YouTube** — пошук відео

Це дає контроль над інтеграціями та допомагає уникати «зайвого» трекінгу через додаткові акаунти.

### Overflow-вікна, необмежені вкладки та справжня робота з багатьма вікнами
Vetale Browser створений для важких сценаріїв із вкладками:
- Створюйте **overflow-вікна** (додаткові вікна для вкладок), щоб тримати робочий простір чистим і при цьому мати фактично **необмежену кількість вкладок**.
- Відкривайте **необмежену кількість основних вікон** — зручно для окремих робочих просторів.
- **Перетягуйте вкладки (drag & drop)** між основними вікнами й overflow-вікнами.

### Інтерфейс — ваш: кольори + розміри + комфорт
Vetale Browser зроблений для тих, хто любить кастомізацію:
- Зміна **фонового кольору** ключових поверхонь (вкладки, панелі, зони вікна)
- Регулювання **розмірів елементів** у головному вікні
- Налаштування **висоти панелі навігації**, **розміру кнопок**, **розміру іконок** та **ширини вкладок**
- Від “компактно” до “просторо” — як вам зручно

### Для дослідників, творців і power users
Окрім перегляду сторінок, Vetale Browser має інструменти для навчання, дебагу й експериментів:
- DevTools/діагностичні сценарії для веб-сторінок
- Підтримка автоматизації/тестування (Playwright-powered)
- Виконання JavaScript у .NET для сценаріїв скриптингу

### Офлайн-розвага, коли потрібно (HexGL)
Коли ви офлайн — або сторінка не завантажилась — Vetale Browser може запропонувати офлайн міні-досвід: **HexGL**.

## Ключові можливості (Key features)
> Примітка: точний набір функцій може відрізнятися залежно від версії застосунку.

- **Вбудований локальний AI-помічник** (Gemma 3, on-device за наявності)
- Підсумки, перефразування, пояснення та brainstorming
- Швидкі чернетки під час перегляду (нотатки, повідомлення, описи)
- Відчуття “native app”, а не обгортки сайту
- Текстовий пошук, вбудований у браузер
- Опційний **режим відповіді** на базі **безкоштовного досвіду Perplexity AI** (залежить від доступності/налаштувань)
- **Overflow-вікна**: порядок у браузингу при зростанні кількості вкладок
- Фактично **необмежені вкладки** через overflow-вікна
- **Необмежена кількість основних вікон** для окремих робочих просторів
- **Drag & drop вкладок** між основними вікнами та overflow-вікнами
- Пошук зображень через **API-ключі Unsplash** (ваші ключі)
- Пошук зображень/відео через **API-ключі Pexels** (ваші ключі)
- Пошук відео через **API-ключі YouTube** (ваші ключі)
- Ключі зберігаються **локально** для вашої конфігурації
- Кастомізація фонового кольору головного вікна
- Fluent-подібний вигляд з регульованими відступами і комфортом
- Голосовий ввід (потрібен дозвіл на мікрофон)
- Підтримка локального пайплайну розпізнавання мовлення (Whisper-based)
- Вбудована діагностика / DevTools workflow
- Підтримка веб-автоматизації/тестування (Playwright-powered)
- Вбудована гра **HexGL**, доступна офлайн або при помилках
- Налаштування застосунку зберігаються локально

## Приватність (Privacy)
Vetale Browser має суворий підхід до приватності:
- **Немає телеметрії розробнику**
- **Немає аналітики, що надсилається розробнику**
- **Немає передачі даних розробнику** — ваші налаштування та дані застосунку залишаються на пристрої
- Налаштування й конфігурація сервісів (включно з API-ключами) зберігаються **локально**
- Браузер завантажує веб-сторінки з інтернету як будь-який інший браузер (сайти можуть збирати дані за власними політиками)
- Доступ до мікрофона використовується лише для голосових функцій і тільки після вашого дозволу

## Системні вимоги (System requirements)
- **ОС:** Windows
- **Архітектура:** x64 / x86 / ARM64 (залежить від пакета в Store)
- **Диск:** може знадобитися додаткове місце для локальних AI/Whisper моделей (залежить від розміру моделей)
- **Для локального AI (рекомендовано):** CPU з підтримкою **AVX2**
