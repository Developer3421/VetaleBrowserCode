# Download Manager (Менеджер завантажень)

Сучасний менеджер завантажень для Vetale Browser:

## Можливості
- Окреме вікно `DownloadsWindow` з автоматичним відкриттям при першій активній завантаженій.
- Список завантажень з прогрес-баром, швидкістю, ETA, розміром.
- Команди: Відкрити файл, Відкрити папку, Скасувати, Повторити.
- Автоматичне визначення стандартної папки завантажень: `%UserProfile%/Downloads/VetaleBrowser`.
- Уникнення конфліктів імен (додає `(1)`, `(2)` і т.д.).
- AES шифрування чутливих полів (URL, ім'я файлу, шлях, тип вмісту, повідомлення помилок) через `DownloadDatabaseService`.
- Збереження історії завантажень (LiteDB) з архівацією старих записів.
- Обробка невідомого Content-Length (прогрес показує лише отримані байти).
- Обчислення середньої швидкості (ковзне вікно 8 секунд) та ETA.

## Архітектура
- `DownloadItem` (модель) в `DatabaseModels.cs`.
- `DownloadDatabaseService` керує шифруванням і доступом до колекції `downloads`.
- `DownloadManager` (глобальний статичний) відповідає за старт, прогрес, завершення і події.
- `DownloadsWindow` відображає поточні та недавні завантаження.
- `ServicesAccessor` зберігає посилання на `DownloadDatabaseService` для UI.

## Статуси
- Pending
- Downloading
- Completed
- Error
- Cancelled

## Розширення
- Додати системні іконки файлів (Shell32) через P/Invoke та кешування.
- Додати кнопку "Очистити завершені" / повне видалення.
- Відновлення незавершених завантажень при рестарті (пауза/резюме з діапазонами HTTP).

## Тестування
Для швидкого тесту можна викликати:
```
await DownloadManager.StartDownloadAsync("https://speed.hetzner.de/100MB.bin");
```
Вікно відкриється автоматично.

## Безпека
Ключ шифрування генерується з MachineName + UserName. У продакшні бажано замінити на захищене сховище (DPAPI). 

## Обмеження
- Немає поки паузи/резюме (потрібно підтримати Range-запити).
- ETA для невідомого розміру (-1) не показується.

## Локалізація
Додаються ключі в `Strings.en.axaml` з префіксом `Downloads.*`.
