- [ ] Перебудувати проект (Build → Rebuild Solution)
- [ ] Переконатися, що немає помилок компіляції
- [ ] Запустити Vetale Browser

## 1. Перевірка UI

### Тулбар AI Chat:
- [ ] Немає кнопки "Enable Reasoning" / "💭 Reasoning"
- [ ] Є селектор мови (🌐)
- [ ] Є кнопки "New Chat" (➕) та "Clear History" (🗑️)
- [ ] Тулбар виглядає чисто і не має пустих місць

---

## 2. Перевірка автовиконання плану

### Тестові запити:

#### Тест 1: Просте питання
**Запит:** "Explain how neural networks work"

**Очікується:**
```
Plan:
1. [Крок 1]
2. [Крок 2]
3. [Крок 3]

[Повна детальна відповідь...]
```

- [ ] План створено (2-5 пунктів)
- [ ] Після плану є порожній рядок
- [ ] Після порожнього рядка йде повна відповідь
- [ ] Відповідь виконує всі кроки плану
- [ ] Модель НЕ зупинилася після плану

#### Тест 2: Україномовний запит
**Запит:** "Поясни як працює інтернет"

**Очікується:**
- [ ] План українською мовою
- [ ] Відповідь українською мовою
- [ ] План виконано повністю

#### Тест 3: Технічне питання з кодом
**Запит:** "Write a C# function to reverse a string"

**Очікується:**
- [ ] План створено
- [ ] Код надано після плану
- [ ] Код працює і є коментарі

#### Тест 4: Довга відповідь
**Запит:** "Write a detailed guide on how to create a web browser from scratch"

**Очікується:**
- [ ] План створено
- [ ] Відповідь довга (можливо кілька абзаців)
- [ ] Відповідь НЕ обрізана на 12000 символів (тепер ліміт 24000)
- [ ] Всі кроки виконано

---

## 3. Перевірка лімітів та фільтрування

### Довгі відповіді:
- [ ] AI може генерувати відповіді довші за попередні
- [ ] Відповіді не обрізаються передчасно
- [ ] Немає артефактів обрізання (неповні речення)

### Спеціальні символи:
**Запит:** "Show me ASCII art of a cat"

- [ ] ASCII-арт відображається правильно
- [ ] Спеціальні символи не фільтруються

### Код з різними символами:
**Запит:** "Write Python code with emoji comments"

- [ ] Код з emoji коментарями працює
- [ ] Символи не видаляються

---

## 4. Перевірка захисту від проблем

### Самодіалог:
- [ ] AI НЕ починає симулювати діалог "User: ... Assistant: ..."
- [ ] Немає префіксів ролей у відповіді

### Нескінченна генерація:
- [ ] AI зупиняється після завершення відповіді
- [ ] Немає нескінченних циклів
- [ ] Кнопка Stop працює коректно

### Повтори:
- [ ] Немає явних повторів великих блоків тексту
- [ ] Немає спаму однакових символів (aaaaa...)

---

## 5. Перевірка різних мов

### Українська:
- [ ] План та відповідь українською
- [ ] Правильна граматика

### Англійська:
- [ ] План та відповідь англійською
- [ ] Природний текст

### Auto-detect:
- [ ] AI визначає мову запиту
- [ ] Відповідає тією ж мовою

---

## 6. Функціональність

### Streaming:
- [ ] Текст з'являється поступово (streaming)
- [ ] План з'являється спочатку
- [ ] Відповідь продовжує з'являтися після плану
- [ ] Автопрокрутка працює

### Stop button:
- [ ] Кнопка Stop з'являється під час генерації
- [ ] Stop зупиняє генерацію
- [ ] Кнопка зникає після зупинки

### New Chat:
- [ ] Очищує історію
- [ ] Починає нову сесію
- [ ] AI працює після скидання

---

## 7. Edge cases

### Дуже короткий запит:
**Запит:** "Hi"

- [ ] AI все ще створює мінімальний план
- [ ] Надає відповідь

### Дуже довгий запит:
**Запит:** [Багато тексту]

- [ ] AI обробляє довгий запит
- [ ] Створює релевантний план
- [ ] Виконує план

### Запит з кодом:
**Запит:** "Fix this code: [код з помилкою]"

- [ ] AI створює план виправлення
- [ ] Надає виправлений код
- [ ] Пояснює зміни
