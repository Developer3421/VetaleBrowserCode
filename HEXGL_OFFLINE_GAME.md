# HexGL Offline Game Integration

## Огляд

Браузер VetaleBrowser тепер включає офлайн гру **HexGL** - футуристичну гоночну гру на HTML5, WebGL та JavaScript.

## Розробник

**HexGL** створено **Thibaut Despoulain** (BKcore)
- Офіційний сайт: [bkcore.com](http://bkcore.com)
- Оригінальний проект: [hexgl.bkcore.com](http://hexgl.bkcore.com)
- GitHub: [github.com/BKcore/HexGL](https://github.com/BKcore/HexGL)

## Як запустити гру

Гра **HexGL** доступна безпосередньо зі сторінки помилки браузера:

1. Коли виникає помилка завантаження сторінки (наприклад, немає з'єднання з інтернетом)
2. На сторінці помилки з'явиться кнопка **"🎮 Грати в гру"**
3. Натисніть на кнопку, щоб запустити гру HexGL

## Системні вимоги

- **WebGL підтримка** - обов'язково!
- Сучасна відеокарта з підтримкою OpenGL 2.0+
- Драйвери відеокарти повинні бути актуальні

### WebGL налаштування в браузері

Браузер VetaleBrowser налаштований для підтримки WebGL ігор:
- `enable-webgl` та `enable-webgl2` увімкнені
- `ignore-gpu-blocklist` - дозволяє GPU навіть якщо драйвер у чорному списку
- `enable-gpu-rasterization` - апаратне прискорення растеризації
- `enable-accelerated-2d-canvas` - апаратне прискорення 2D canvas

## Усунення проблем

### Гра показує тільки меню, не запускається

Це означає, що WebGL не працює. Можливі причини:

1. **Вимкнено апаратне прискорення** - перевірте налаштування системи
2. **Застарілі драйвери відеокарти** - оновіть драйвери
3. **Відеокарта не підтримує WebGL** - спробуйте на іншому комп'ютері

### Для перевірки WebGL

Відкрийте в браузері `chrome://gpu` для перевірки статусу GPU акселерації.

### Для AMD відеокарт (RX 5700 XT тощо)

Браузер використовує OpenGL ANGLE замість D3D11 для кращої сумісності з AMD картами.

## Технічна реалізація

### Локальний HTTP сервер

Гра запускається через вбудований локальний HTTP сервер для вирішення проблем з `file://` URLs:

- **LocalGameServer.cs** - синглтон HTTP сервер
- Автоматично знаходить вільний порт (8080-9000)
- Роздає статичні файли гри з правильними MIME типами
- Додає CORS заголовки для кросс-доменних запитів
- URL гри: `http://localhost:PORT/index.html`

### Розташування файлів гри

```
VetaleBrowser/
├── VetaleBrowserOfflineGame/
│   └── HexGL-master/
│       ├── index.html          # Головний файл гри
│       ├── launch.js           # Скрипт запуску
│       ├── css/                # Стилі
│       ├── libs/               # Бібліотеки (Three.js, etc.)
│       ├── bkcore/             # Логіка гри
│       ├── textures/           # Текстури
│       ├── geometries/         # 3D моделі
│       └── audio/              # Звуки
```

### Компоненти інтеграції

1. **BrowserErrorPage.axaml** - кнопка "Грати в гру" на сторінці помилки
2. **BrowserErrorPage.axaml.cs** - подія `PlayGameRequested`
3. **MainWindow.axaml.cs** - обробка запуску гри та оновлення UI
4. **Strings.uk.axaml / Strings.en.axaml** - локалізація

### Адреса гри

Коли гра запущена, в адресному рядку відображається:
```
http://localhost:PORT/index.html
```

Де PORT - автоматично обраний вільний порт (зазвичай 8080).

### Іконка гри

Вкладка з грою HexGL показує оригінальну іконку гри (`icon_32.png`), яка завантажується з локального сервера.
