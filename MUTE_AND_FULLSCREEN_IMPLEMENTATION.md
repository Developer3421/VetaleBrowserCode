# Реалізація муту звуку та повноекранного режиму

## Огляд

Цей документ описує реалізацію функціоналу вимкнення звуку (мут) для вкладок та повноекранного режиму для відео контенту в VetaleBrowser.

## Мут звуку для вкладки

### Архітектура

Функціонал муту реалізований на **рівні процесу браузера (CEF/Chromium Host)**, а не на рівні окремих медіа елементів. Це означає:

1. **Мут застосовується до всього процесу** - через CefBrowserHost.SetAudioMuted()
2. **Стан зберігається між вкладками** - мут НЕ скидається при перемиканні вкладок
3. **Звук відновлюється тільки при явному розмучуванні** користувачем

### Компоненти

#### TabWorker (`VetaleBrowser.Core\Scripts\Models\TabWorker.cs`)

- **Властивість `IsMuted`**: Зберігає стан муту для вкладки
- **Метод `ToggleMute()`**: Перемикає стан муту
- **Метод `ApplyMuteState()`**: Застосовує стан муту через CefBrowserHost
  - **Пріоритет 1**: Намагається знайти `BrowserHost` і викликати `SetAudioMuted()`
  - **Пріоритет 2**: Використовує властивість `IsAudioMuted` через reflection
  - **Пріоритет 3**: Шукає CEF Browser і його Host для виклику `SetAudioMuted()`

```csharp
// Приклад доступу до BrowserHost
var browserHost = WebView.GetType().GetProperty("BrowserHost")?.GetValue(WebView);
browserHost.GetType().GetMethod("SetAudioMuted")?.Invoke(browserHost, new object[] { isMuted });
```

#### Tab UI Control (`VetaleBrowser.UI\Еlements\Tab.axaml.cs`)

- **Властивість `IsMuted`**: Відображає стан муту в UI
- **Подія `MuteToggled`**: Генерується при натисканні на кнопку муту
- **Кнопка муту**: Відображається в заголовку вкладки

#### MainWindow (`MainWindow.axaml.cs`)

- **Обробник події `MuteToggled`**: Викликає `worker.ToggleMute()` при натисканні
- **Синхронізація UI**: Оновлює стан кнопки муту при перемиканні вкладок
- **Збереження стану**: При `ActivateWorker()` синхронізується `tab.IsMuted = worker.IsMuted`

### Використання

1. Користувач натискає кнопку муту в заголовку вкладки
2. Tab control генерує подію `MuteToggled`
3. MainWindow викликає `worker.ToggleMute()`
4. TabWorker перемикає `IsMuted` властивість
5. `ApplyMuteState()` застосовує зміни через `CefBrowserHost.SetAudioMuted()`
6. **Мут застосовується до всього процесу браузера**
7. При перемиканні вкладок UI синхронізується, але стан НЕ змінюється

### Важливо

- **Мут на рівні процесу**: Коли одна вкладка замучена, звук давиться для всього браузера
- **Стан зберігається**: Перемикання між вкладками НЕ відновлює звук
- **Явне розмучування**: Звук відновлюється тільки при повторному натисканні кнопки муту

## Повноекранний режим

### Архітектура

Повноекранний режим підтримує два сценарії:

1. **Ініціювання користувачем** - натискання F11 для перемикання повноекранного режиму браузера
2. **Ініціювання веб-контентом** - відео елементи (YouTube, інші відеоплеєри) запитують повноекранний режим

**Ключова особливість**: WebView займає **весь обсяг вікна** через `Grid.RowSpan = 3` та `ZIndex = 1000`

### Компоненти

#### TabWorker

- **Подія `FullscreenChanged`**: Генерується при зміні повноекранного режиму WebView
- **Метод `TryHookFullscreenEvents()`**: Підписується на події fullscreen від WebView через reflection
  - Шукає подію `IsFullscreenChanged` у WebView
  - Підписується на неї і передає зміни через власну подію

#### MainWindow

- **Поля стану**:
  - `_isFullscreen`: Поточний стан повноекранного режиму
  - `_preFullscreenWindowState`: Збережений стан вікна до входу в повноекранний режим
  - `_tabBarRow`, `_navigationBarRow`: Посилання на UI елементи для приховування
  - `_webViewContainer`: Контейнер WebView для маніпуляцій з розміром

- **Методи**:
  - `EnterFullscreen()`: Входить в повноекранний режим
    - Ховає панель вкладок та навігаційну панель (`IsVisible = false`)
    - **Розтягує WebView на всі 3 рядки Grid** (`Grid.SetRowSpan = 3`)
    - **Виносить WebView на передній план** (`ZIndex = 1000`)
    - Прибирає відступи (`Margin = 0`)
    - Встановлює `WindowState.FullScreen`
    - Прибирає декорації вікна (`SystemDecorations = None`)
  - `ExitFullscreen()`: Виходить з повноекранного режиму
    - **Повертає WebView до одного рядка** (`Grid.SetRowSpan = 1`)
    - **Скидає ZIndex** (`ZIndex = 0`)
    - Показує панель вкладок та навігаційну панель
    - Відновлює попередній стан вікна
    - Відновлює декорації вікна
  - `ToggleFullscreen()`: Перемикає повноекранний режим

- **Обробники подій**:
  - `OnWorkerFullscreenChanged()`: Реагує на зміни fullscreen від WebView
  - `OnWindowKeyDown()`: Обробляє F11 та Escape для керування fullscreen

### Потік виконання

#### Повноекранний режим для відео

1. Користувач натискає кнопку fullscreen на відео (YouTube тощо)
2. WebView генерує подію fullscreen (або виявляється через JavaScript)
3. TabWorker ловить цю подію і генерує `FullscreenChanged`
4. MainWindow отримує подію через `OnWorkerFullscreenChanged`
5. Викликається `EnterFullscreen()`:
   - UI панелі стають невидимими
   - **WebView розтягується на всі 3 рядки Grid**
   - **WebView виноситься на передній план (ZIndex = 1000)**
   - Вікно переходить в WindowState.FullScreen
6. **WebView займає весь обсяг вікна**, жодних інших елементів не видно
7. При виході (Escape або кнопка) → `ExitFullscreen()`:
   - WebView повертається до рядка 2 (Grid.Row = 2, RowSpan = 1)
   - ZIndex скидається
   - UI панелі знову видимі

#### Повноекранний режим браузера (F11)

1. Користувач натискає F11
2. `OnWindowKeyDown()` ловить подію
3. Викликається `ToggleFullscreen()`
4. UI перемикається між звичайним та повноекранним режимом
5. **WebView займає весь екран так само, як і для відео**

### Особливості

- **WebView на весь екран**: Через `Grid.RowSpan = 3` WebView займає всі рядки батьківського Grid
- **ZIndex для накладання**: WebView виноситься на передній план, перекриваючи всі інші елементи
- **Escape виходить з fullscreen**: Натискання Escape завжди виводить з повноекранного режиму
- **Збереження стану**: Стан вікна перед fullscreen зберігається і відновлюється
- **Повна видимість WebView**: В fullscreen режимі видно тільки вміст WebView
- **Робота з поточною вкладкою**: Fullscreen застосовується до активного worker WebView

## Технічні деталі

### Використання Reflection

Обидві функції використовують reflection для роботи з WebViewControl, оскільки:

1. WebViewControl може мати різні версії API
2. Деякі властивості/події можуть бути недоступні в певних версіях
3. Це дозволяє fallback до альтернативних методів

### Мут на рівні процесу

Ключова відмінність від простих реалізацій:

- **Не JavaScript**: Не використовується `element.muted = true`
- **Рівень CEF**: Викликається `CefBrowserHost.SetAudioMuted()`
- **Глобальний ефект**: Мутить весь процес рендерингу
- **Переваги**:
  - Працює для всіх аудіо джерел (не тільки `<audio>` та `<video>`)
  - Не обходиться скриптами на сторінці
  - Стан зберігається між навігацією
  - Не залежить від Content Security Policy (CSP)

### Fullscreen через Grid.RowSpan

Замість створення нового вікна або overlay:

- **Grid.RowSpan = 3**: WebView розтягується на всі рядки
- **ZIndex = 1000**: WebView накладається поверх всіх інших елементів
- **IsVisible = false**: UI панелі стають невидимими
- **Margin = 0**: Прибираються всі відступи

Це забезпечує:
- WebView займає **точно весь обсяг вікна**
- Немає артефактів перемальовування
- Швидке перемикання (без створення нових контролів)

### Debug логування

Обидві функції включають детальне логування для діагностики:

```csharp
// Мут
System.Diagnostics.Debug.WriteLine($"[TabWorker] Audio muted via BrowserHost.SetAudioMuted: {_isMuted}");

// Fullscreen
System.Diagnostics.Debug.WriteLine($"[MainWindow] Entering fullscreen");
System.Diagnostics.Debug.WriteLine($"[MainWindow] WebView RowSpan set to 3, ZIndex to 1000");
```

Це допомагає відстежувати роботу функціоналу під час розробки та тестування.

## Потенційні покращення

1. **Індикатор звуку**: Показувати іконку динаміка на вкладці, якщо сторінка відтворює звук
2. **Глобальний мут UI**: Показувати глобальний стан муту в статус барі
3. **Fullscreen для окремих елементів**: Підтримка fullscreen не тільки для відео, але й для інших елементів
4. **Picture-in-Picture**: Підтримка режиму "картинка в картинці" для відео
5. **Анімація переходу**: Плавна анімація при вході/виході з fullscreen
6. **Збереження розміру**: Запам'ятовувати позицію вікна перед fullscreen

## Тестування

### Тестування муту

1. Відкрити YouTube відео
2. Натиснути кнопку муту на вкладці
3. Переконатися, що звук вимкнувся
4. **Перемкнутися на іншу вкладку** - звук залишається вимкненим
5. **Відкрити нову вкладку з відео** - звук не відтворюється
6. Натиснути кнопку муту ще раз - звук має відновитися для всіх вкладок

### Тестування fullscreen

1. **Від відео**:
   - Відкрити YouTube відео
   - Натиснути fullscreen на плеєрі
   - Переконатися, що **WebView займає весь екран вікна**
   - Не видно панелей, вкладок, жодних UI елементів
   - Натиснути Escape - має вийти з fullscreen, WebView повертається до нормального розміру

2. **Від браузера**:
   - Натиснути F11
   - Переконатися, що **WebView займає весь екран**
   - Натиснути F11 знову - має вийти з fullscreen

3. **Перевірка розміру**:
   - В fullscreen режимі WebView має займати **весь обсяг вікна**
   - Немає пустих місць, відступів, або видимих UI елементів
   - При виході WebView повертається точно до попереднього розміру
