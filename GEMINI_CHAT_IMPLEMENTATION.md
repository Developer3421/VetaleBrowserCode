## 🎯 Як користуватися

### Базове використання

1. **Відкрити чат**
   - Меню → Tools → Gemini Chat
   - Або гаряча клавіша `Ctrl+G`

2. **Написати повідомлення**
   - Клацнути в поле внизу
   - Ввести текст
   - Натиснути `Ctrl+Enter` або ➤

3. **Отримати відповідь**
   - Зачекати 1-3 секунди
   - Gemini згенерує відповідь
   - Відповідь з'явиться в чаті

4. **Очистити чат**
   - Натиснути 🗑️ у заголовку

## 🛠️ Технічні деталі

### Архітектура

```
GeminiChatPanel (UI)
    ↓
GeminiAiSummaryService
    ↓
Google Gemini API
```

### Потік даних

1. Користувач вводить текст
2. `SendMessage()` → `GenerateResponseAsync()`
3. `GenerateChatResponseAsync()` викликає API
4. Відповідь парситься
5. `AddAssistantMessage()` додає в UI
6. Автопрокрутка вниз

### Обробка помилок

```csharp
try {
    var summary = await _geminiService.GenerateChatResponseAsync(message);
    
    if (summary.State == AiSummaryState.Ready) {
        AddAssistantMessage(summary.SummaryText);
    } else if (summary.State == AiSummaryState.Error) {
        AddAssistantMessage($"❌ {summary.ErrorMessage}");
    }
} catch (Exception ex) {
    AddAssistantMessage($"❌ Помилка: {ex.Message}");
}
```

## 🐛 Відомі проблеми

### 1. Немає історії чатів
**Проблема:** При закритті панелі чат очищується  
**Рішення:** Планується додати збереження сесій

**Проблема:** Gemini не пам'ятає попередні повідомлення  
**Рішення:** Потрібно передавати історію в API

### 3. Прості текстові відповіді
**Проблема:** Немає форматування (bold, code, списки)  
**Рішення:** Додати Markdown рендерер
