## 🔑 Що потрібно зробити для запуску

### Крок 1: Отримати API ключ (ОБОВ'ЯЗКОВО)

1. Відкрийте: https://aistudio.google.com/app/apikey
2. Увійдіть через Google акаунт
3. Натисніть "Create API key"
4. Скопіюйте ключ (починається з `AIzaSy...`)

### Крок 2: Налаштувати ключ

**Варіант А (в коді):**
Відкрийте файл:
```
VetaleBrowser\VetaleBrowser.Search\Services\GeminiAiSummaryService.cs
```

Знайдіть рядок ~44:
```csharp
private const string ApiKey = "YOUR_GEMINI_API_KEY_HERE";
```

Замініть на ваш ключ:
```csharp
private const string ApiKey = "AIzaSyВАШ_КЛЮЧ_ТУТ";
```

**Варіант Б (змінна середовища - рекомендовано):**
```powershell
[System.Environment]::SetEnvironmentVariable('GEMINI_API_KEY', 'AIzaSyВАШ_КЛЮЧ', 'User')
```

### Крок 3: Перезапустити додаток
Після налаштування ключа просто перезапустіть Vetale Browser.

## 🔍 Діагностика

### Перевірка в Debug консолі

При запуску ви побачите:
```
[GeminiAiSummary] Service initialized with Google Gemini
[GeminiAiSummary] Model: gemini-1.5-flash
[GeminiAiSummary] API Key configured: AIzaSy...
```

При пошуку:
```
[GeminiAiSummary] Sending request for query: як приготувати борщ
[GeminiAiSummary] Response Status: OK (200)
[GeminiAiSummary] ✓ Summary generated successfully!
```

### Можливі помилки

**"API ключ не налаштовано"**
- Встановіть ключ у GeminiAiSummaryService.cs або через GEMINI_API_KEY

**"Невірний API ключ" (401/403)**
- Перевірте правильність ключа
- Створіть новий ключ на https://aistudio.google.com/app/apikey

**"Перевищено ліміт" (429)**
- Зачекайте 1 хвилину
- Ліміт: 15 запитів на хвилину
