## 🔍 Діагностика проблем:

### Якщо UI елементи NOT FOUND:
→ Перевірте логи: `[VetaleSearchResultsPage] AI Summary UI Elements:`  
→ Має бути: `FOUND` для всіх елементів

### Якщо API error:
→ Перевірте інтернет-з'єднання  
→ Спробуйте ручний тест PowerShell  
→ Подивіться `[QwenAiSummary] API error:` у логах

### Якщо timeout:
→ Збільште timeout (зараз 30 сек)  
→ Спробуйте пізніше (API може бути перевантажений)

### Якщо порожня відповідь:
→ Перевірте `[QwenAiSummary] Data array length:`  
→ Має бути > 0
