# 🛠️ DevTools - Інструменти Розробника

## Швидкий Старт

### Як Відкрити DevTools

1. Відкрийте веб-сторінку у VetaleBrowser
2. Перейдіть до меню **Tools → DevTools**
3. Відкриється вікно DevTools з вкладками

### Основні Вкладки

#### 📦 Application - Сховище
**Що робить:** Показує localStorage, sessionStorage та cookies

**Як користуватись:**
1. Натисніть кнопку **"Capture Storage"**
2. Дочекайтесь завершення (кнопка покаже "⏳ Capturing...")
3. Автоматично відкриється localStorage
4. Виберіть тип сховища зліва
5. Переглядайте ключі та значення справа

**Приклад:**
```
localStorage (15 items)
├── user_id = "12345"
├── theme = "dark"
└── language = "ua"
```

#### 🔍 Elements - DOM Структура
**Що робить:** Показує HTML структуру сторінки

**Як користуватись:**
1. Натисніть кнопку **"Capture DOM"**
2. Дочекайтесь побудови дерева (кнопка покаже "⏳ Capturing...")
3. Дерево автоматично розгорнеться на першому рівні
4. Виберіть елемент, щоб побачити:
   - **Атрибути** (id, class, href, src і т.д.)
   - **Стилі** (display, color, font-size і т.д.)

**Приклад:**
```
<html>
  └─ <body>
      ├─ <header>
      │   └─ <nav>
      └─ <main>
          └─ <div class="content">
```

#### ⚡ Performance - Продуктивність
**Що робить:** Аналізує швидкість завантаження сторінки

**Як користуватись:**
1. Натисніть кнопку **"Capture Performance"**
2. Дочекайтесь аналізу (кнопка покаже "⏳ Analyzing...")
3. Переглядайте метрики:
   - **Load Time** - Час повного завантаження
   - **DOM Load Time** - Час парсингу HTML
   - **First Paint** - Перша відмальовка
   - **Memory** - Використання пам'яті

**Приклад:**
```
Load Time: 1234 ms
DOM Load Time: 890 ms
First Paint: 567 ms
Memory: 45.23 MB
```

#### 🌐 Network - Мережа
**Що робить:** Показує всі завантажені ресурси

**Як користуватись:**
1. Натисніть кнопку **"Capture Network"**
2. Дочекайтесь завершення (кнопка покаже "⏳ Capturing...")
3. Переглядайте список ресурсів:
   - 📄 **Scripts** (.js файли)
   - 🎨 **Styles** (.css файли)
   - 🖼️ **Images** (зображення)
   - 📝 **Documents** (HTML)

**Приклад:**
```
📄 script    | main.js          | 125 KB | ✓
🎨 stylesheet| style.css        | 45 KB  | ✓
🖼️ image     | logo.png         | 15 KB  | ✓
```

#### 📁 Sources - Джерела
**Що робить:** Показує вихідний код файлів

**Як користуватись:**
1. Натисніть кнопку **"Capture Sources"**
2. Дочекайтесь завершення (кнопка покаже "⏳ Capturing...")
3. Виберіть файл у дереві зліва
4. Переглядайте код справа

**Приклад:**
```
📁 Sources
├─ 📄 https://example.com/main.js
├─ 🎨 https://example.com/style.css
└─ 📝 inline-script-0
```

## Поради та Трюки

### 💡 Корисні Функції

#### 1. Автоматичний Вибір
- **Application**: Автоматично вибирає localStorage (найчастіше використовується)
- **Elements**: Розгортає перший рівень DOM для швидкого доступу

#### 2. Візуальний Фідбек
- Всі кнопки показують стан: "⏳ Capturing...", "⏳ Analyzing..."
- Кнопки блокуються під час роботи (не можна натиснути двічі)
- Автоматичне повернення до норми після завершення

#### 3. Інформаційні Повідомлення
```
✓ Успішно: "Captured 15 storage items from https://example.com"
⚠ Попередження: "No active tab found. Please open a webpage first."
❌ Помилка: "Error: Connection timeout"
```

#### 4. Очищення Даних
- Кнопка **"Clear"** на кожній вкладці
- Очищає тільки відображення, не впливає на сторінку
- Дані можна захопити знову

### 🚀 Швидкі Команди

| Дія | Кнопка | Результат |
|-----|--------|-----------|
| Захопити Storage | Capture Storage | Показує localStorage, sessionStorage, cookies |
| Захопити DOM | Capture DOM | Будує дерево HTML елементів |
| Аналіз Performance | Capture Performance | Показує метрики швидкості |
| Захопити Network | Capture Network | Список всіх ресурсів |
| Захопити Sources | Capture Sources | Вихідний код файлів |
| Очистити | Clear | Очищає поточну вкладку |

### ⚙️ Налаштування

#### Як DevTools Працює

1. **Автоматична Синхронізація**
   - DevTools автоматично знаходить активну вкладку браузера
   - Використовує URL поточної сторінки
   - Не потрібно вручну вказувати сторінку

2. **Headless Playwright**
   - Всі дані захоплюються через headless Chromium
   - Не впливає на основний браузер
   - Працює швидко та надійно

3. **UI Thread Safety**
   - Всі оновлення UI виконуються у правильному потоці
   - Немає зависань інтерфейсу
   - Плавна робота

### 📊 Використання Пам'яті

DevTools використовує мінімум ресурсів:
- **Singleton Pattern**: Один екземпляр Playwright для всіх сторінок
- **Lazy Initialization**: Playwright запускається тільки при першому використанні
- **Headless Mode**: Chromium працює у фоні без GUI

### 🔧 Розв'язання Проблем

#### Проблема: "No active tab found"
**Рішення:** Відкрийте веб-сторінку у VetaleBrowser перед використанням DevTools

#### Проблема: Кнопка не реагує
**Рішення:** Дочекайтесь завершення попередньої операції (кнопка розблокується)

#### Проблема: Порожній список після Capture
**Рішення:** 
1. Перевірте, чи сторінка повністю завантажена
2. Спробуйте ще раз через кілька секунд
3. Перевірте Debug Output у консолі

#### Проблема: Повільна робота
**Рішення:**
1. Перший запуск може бути повільнішим (встановлення Playwright)
2. Наступні запуски працюють швидко
3. Закрийте непотрібні вкладки браузера

## Приклади Використання

```
3. Натисніть "Capture Storage"
4. Виберіть "cookies" у списку зліва
```

```
1. Відкрийте будь-яку веб-сторінку

3. Натисніть "Capture DOM"

```

```
2. Відкрийте DevTools → Performance
3. Натисніть "Capture Performance"
4. Дивіться:
   - Load Time (повне завантаження)
   - DOM Load (парсинг HTML)
   - First Paint (перша відмальовка)
```

```
1. Відкрийте будь-яку сторінку

3. Натисніть "Capture Network"

```


## Часті Запитання (FAQ)

### Q: Чи можна використовувати DevTools без інтернету?
**A:** Так, після першого запуску (встановлення Playwright). DevTools працює локально.

### Q: Чи зберігаються дані між сеансами?
**A:** Так, всі захоплені дані зберігаються в базі SQLite у папці проекту.

### Q: Скільки пам'яті використовує DevTools?
**A:** ~100-200 MB для headless Chromium. Один екземпляр для всіх вкладок DevTools.

### Q: Чи можна експортувати дані?
**A:** В поточній версії - ні. Планується в майбутніх оновленнях.

### Q: Чи впливає DevTools на швидкість браузера?
**A:** Ні, DevTools працює в окремому процесі через headless Playwright.

### Q: Що робити, якщо DevTools не відкривається?
**A:** Перевірте, чи встановлений .NET 8 SDK та чи є права на запуск Playwright.
