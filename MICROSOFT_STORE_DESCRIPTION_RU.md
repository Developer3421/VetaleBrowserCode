## Короткое описание
Яркий браузер для Windows с **локальным ИИ (Gemma 3)**, глубокой настройкой интерфейса, Vetale Search с ответами Perplexity и строгим подходом **«всё локально»**.

---

## Полное описание
Добро пожаловать в **Vetale Browser** — современный браузер для Windows для тех, кто хочет, чтобы интернет был *персональным*, *мощным* и *приватным*.

Это не просто вкладки и строка поиска. Vetale Browser объединяет:
- **ИИ на устройстве** (Gemma 3) для ежедневного просмотра, письма и обучения
- Интерфейс, который можно **настроить под себя** (цвета, размеры, отступы)
- Более умный поиск: **Vetale Search** + опциональные ответы из **бесплатного опыта Perplexity AI**
- Более приватный поиск медиа через **ваши собственные API-ключи** (Unsplash / Pexels / YouTube)
- Жёсткое обещание: **данные не отправляются разработчику** — всё остаётся на устройстве
- Оконную систему для больших рабочих наборов: **overflow-окна**, **неограниченные вкладки** и **перетаскивание вкладок между окнами**

### Локальный ИИ, который остаётся на вашем ПК (Gemma 3)
Vetale Browser включает AI-помощника, рассчитанного на **локальную** работу с **встроенной моделью Gemma 3** (если модель доступна на вашем устройстве).

Используйте для:
- Быстрых пересказов статей и длинных страниц
- Переписывания текста (яснее, короче, профессиональнее)
- Объяснения понятий (от простых до технических)
- Генерации идей и планов
- Черновиков заметок/сообщений во время просмотра

### Vetale Search: классический поиск + умные ответы
В Vetale Browser есть **Vetale Search**:
- Введите обычный запрос и получите классические текстовые результаты.
- Опционально включайте режим ответа/объяснения, основанный на **бесплатном опыте Perplexity AI** (зависит от доступности/настроек).

### Более приватный поиск изображений и видео (ваши ключи)
Для поиска изображений и видео Vetale Browser может использовать **ваши собственные API-ключи**:
- **Unsplash** — поиск изображений
- **Pexels** — поиск изображений и видео
- **YouTube** — поиск видео

### Overflow-окна, неограниченные вкладки и полноценная работа с несколькими окнами
Для тяжёлых сценариев со вкладками:
- **Overflow-окна** помогают держать рабочее пространство чистым и дают фактически **неограниченное число вкладок**.
- **Неограниченное число основных окон** для отдельных рабочих пространств.
- **Drag & drop** вкладок между основными окнами и overflow-окнами.

### Интерфейс — ваш: цвета + размеры + комфорт
- Настройка фоновых цветов ключевых областей
- Регулировка размеров элементов
- Настройка высоты панели навигации, кнопок, иконок и ширины вкладок

### Офлайн-мини-опыт (HexGL)
Когда вы офлайн — или страница не загрузилась — Vetale Browser может предложить офлайн-мини-опыт: **HexGL**.

## Ключевые возможности
> Примечание: точный набор функций может отличаться в зависимости от версии приложения.

- **Встроенный локальный AI-помощник** (Gemma 3, on-device при наличии)
- Сводки/пересказы, переписывание, объяснения и brainstorming
- Быстрые черновики во время просмотра (заметки, сообщения, описания)
- Ощущение «нативного приложения», а не оболочки сайта
- Текстовый поиск, встроенный в браузер
- Опциональный **режим ответа** на базе **бесплатного опыта Perplexity AI** (зависит от доступности/настроек)
- **Overflow-окна** для масштабирования рабочих наборов вкладок
- Фактически **неограниченные вкладки** через overflow-окна
- **Неограниченное число основных окон** для отдельных рабочих пространств
- **Drag & drop вкладок** между основными окнами и overflow-окнами
- Поиск изображений через **API-ключи Unsplash** (ваши ключи)
- Поиск изображений/видео через **API-ключи Pexels** (ваши ключи)
- Поиск видео через **API-ключи YouTube** (ваши ключи)
- Ключи хранятся **локально** для вашей конфигурации
- Настройка фонового цвета главного окна
- Fluent-подобный внешний вид с настраиваемыми отступами и комфортом
- Голосовой ввод (нужно разрешение на микрофон)
- Поддержка локального распознавания речи (Whisper-based)
- Встроенная диагностика / DevTools workflow
- Поддержка веб-автоматизации/тестирования (Playwright-powered)
- Встроенная игра **HexGL**, доступная офлайн или при ошибках
- Настройки приложения хранятся локально

## Приватность
Vetale Browser создавался со строгим подходом к приватности:
- **Нет телеметрии разработчику**
- **Нет аналитики, отправляемой разработчику**
- **Нет передачи данных разработчику** — ваши настройки и данные приложения остаются на устройстве
- Настройки и конфигурация сервисов (включая API-ключи) хранятся **локально**
- Браузер загружает страницы из интернета, как любой другой браузер (сайты могут собирать данные по своим политикам)
- Доступ к микрофону используется только для голосовых функций и только после вашего разрешения

## Системные требования
- **ОС:** Windows
- **Архитектура:** x64 / x86 / ARM64 (зависит от пакета в Store)
- **Диск:** может потребоваться дополнительное место для локальных AI/Whisper моделей (зависит от размера моделей)
- **Для локального ИИ (рекомендуется):** CPU с поддержкой **AVX2**
