## Переваги компактного дизайну

### 1. Менші відступи
- Margin: 30px → 40,30 (менше зверху/знизу)
- Row spacing: 20px → 15px
- Label margin: 8px → 6px
- Кнопки margin top: 20px → 15px

### 2. Менша іконка
- Зірка: 48px → 32px
- Заголовок: 24px Bold → 20px SemiBold
- Spacing: 10px → 8px

### 3. Менші елементи
- Labels: 14px → 13px
- Buttons width: 120px → 110px
- MaxWidth grid: без обмеження → 500px

### 4. Адаптивний розмір
- Початок: 600x480 (форма)
- Після збереження: 900x700 (список)
- MinWidth/Height також змінюються
