# Інструкції з тестування муту і повноекранного режиму

## Огляд

Ця інструкція допоможе перевірити працездатність функцій муту звуку та повноекранного режиму в VetaleBrowser.

## Підготовка

1. Запустіть VetaleBrowser
2. Переконайтеся, що браузер успішно завантажився та відображається головна сторінка

## Тестування муту звуку

### Тест 1: Базовий мут на YouTube

1. Відкрийте новий таб (якщо потрібно)
2. Перейдіть на `https://www.youtube.com`
3. Знайдіть будь-яке відео і почніть відтворення
4. Переконайтеся, що чується звук
5. Натисніть кнопку муту в заголовку вкладки (іконка динаміка)
6. **Очікуваний результат**: Звук має вимкнутися
7. Натисніть кнопку муту ще раз
8. **Очікуваний результат**: Звук має відновитися

### Тест 2: Мут на різних сайтах

Повторіть Тест 1 для:
- `https://soundcloud.com` (музика)
- `https://vimeo.com` (відео)
- Будь-який інший сайт з медіа контентом

### Тест 3: Мут між вкладками

1. Відкрийте 2-3 вкладки з різними відео/аудіо
2. Увімкніть відтворення в усіх вкладках
3. Замутьте одну вкладку
4. **Очікуваний результат**: Тільки ця вкладка має бути замучена, інші продовжують відтворювати звук
5. Перемикайтеся між вкладками
6. **Очікуваний результат**: Стан муту зберігається для кожної вкладки

### Перевірка Debug логів для муту

Відкрийте Debug Console (Output) і шукайте такі повідомлення:

```
[TabWorker] Audio muted via IsAudioMuted: True
```
або
```
[TabWorker] Audio muted via JavaScript: True
```

Це підтвердить, який метод використовується для муту.

## Тестування повноекранного режиму

### Тест 4: Fullscreen через відео (YouTube)

1. Відкрийте `https://www.youtube.com`
2. Почніть відтворення будь-якого відео
3. Натисніть кнопку fullscreen на плеєрі YouTube (іконка в правому нижньому куті)
4. **Очікуваний результат**: 
   - Браузер має перейти в повноекранний режим
   - Панель вкладок і навігаційна панель мають зникнути
   - Відео займає весь екран
5. Натисніть `Escape` або `F11`
6. **Очікуваний результат**: 
   - Браузер виходить з повноекранного режиму
   - UI елементи з'являються знову

### Тест 5: Fullscreen через браузер (F11)

1. Відкрийте будь-яку сторінку
2. Натисніть `F11`
3. **Очікуваний результат**: 
   - Вікно браузера стає повноекранним
   - Панелі ховаються
4. Натисніть `F11` ще раз
5. **Очікуваний результат**: 
   - Браузер виходить з повноекранного режиму
   - Відновлюється попередній розмір вікна

### Тест 6: Fullscreen на різних відео платформах

Повторіть Тест 4 для:
- `https://vimeo.com`
- `https://www.twitch.tv`
- HTML5 відео на будь-якому сайті

### Тест 7: Escape виходить з fullscreen

1. Увійдіть в fullscreen будь-яким способом (F11 або через відео)
2. Натисніть `Escape`
3. **Очікуваний результат**: Завжди має вийти з fullscreen

### Перевірка Debug логів для fullscreen

Відкрийте Debug Console (Output) і шукайте такі повідомлення:

При вході в fullscreen:
```
[MainWindow] Worker fullscreen changed: True
[MainWindow] Entering fullscreen
```

При виході з fullscreen:
```
[MainWindow] Worker fullscreen changed: False
[MainWindow] Exiting fullscreen
```

Також може з'явитися:
```
[TabWorker] Hooked to IsFullscreenChanged event
```
або
```
[TabWorker] Fullscreen listener injected via JavaScript
```

## Комбіновані тести

### Тест 8: Мут + Fullscreen

1. Відкрийте YouTube відео
2. Почніть відтворення зі звуком
3. Натисніть fullscreen на плеєрі
4. Перемкніться на вкладку (якщо можливо побачити)
5. Замутьте вкладку
6. **Очікуваний результат**: Відео в fullscreen без звуку
7. Вийдіть з fullscreen
8. **Очікуваний результат**: Мут залишається активним

### Тест 9: Множинні вкладки з fullscreen

1. Відкрийте 2 вкладки з відео
2. У першій вкладці увійдіть в fullscreen через відео
3. Натисніть Escape
4. Перемкніться на другу вкладку
5. Увійдіть в fullscreen через відео
6. **Очікуваний результат**: Fullscreen працює правильно для обох вкладок

## Відомі обмеження

1. **JavaScript fallback для муту**: Якщо WebViewControl не підтримує `IsAudioMuted`, використовується JavaScript. Це означає:
   - Мут застосовується тільки до існуючих `<audio>` та `<video>` елементів
   - Динамічно додані елементи можуть не бути замучені
   - Потрібно знову застосувати мут після перезавантаження сторінки

2. **Fullscreen detection**: Якщо WebView не генерує події fullscreen:
   - JavaScript слухач впроваджується на сторінку
   - Може не працювати на деяких сайтах з Content Security Policy (CSP)

3. **Перезавантаження сторінки**: Мут може скинутися при перезавантаженні, якщо використовується JavaScript метод

## Діагностика

### Якщо мут не працює:

1. Перевірте Debug лог - який метод використовується?
2. Якщо "No method found to execute JavaScript":
   - WebView може не підтримувати виконання скриптів
   - Потрібна інша версія WebViewControl
3. Якщо "Audio muted via JavaScript" але звук є:
   - Можливо, сайт додає елементи динамічно
   - Спробуйте знову замутити після завантаження відео

### Якщо fullscreen не працює:

1. Перевірте Debug лог - чи були знайдені події?
2. Якщо "No fullscreen event found":
   - Використовується JavaScript fallback
   - Може не працювати через CSP
3. Спробуйте F11 - якщо це працює, проблема з detection від відео
4. Якщо F11 не працює - проблема з MainWindow fullscreen логікою
