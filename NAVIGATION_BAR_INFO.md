# Navigation Bar Control - Документація

## Створено панель навігації для Vetale Browser

### Файли:
1. `VetaleBrowser/VetaleBrowser.UI/Еlements/NavigationBar.axaml` - стилі контролу
2. `VetaleBrowser/VetaleBrowser.UI/Еlements/NavigationBar.axaml.cs` - код контролу

### Архітектура:
Панель навігації тепер **самостійно керує всією навігацією браузера**. Вона працює безпосередньо з `WebViewManager`, що значно зменшує код головного вікна.

### Ініціалізація:
```csharp
var navigationBar = this.FindControl<NavigationBar>("NavigationBar");
navigationBar.Initialize(webViewManager); // Передаємо WebViewManager
```

### Розташування:
Панель навігації розміщена на другій лінії головного вікна (Grid.Row="1") з фіолетовим градієнтом фоном.

### Кнопки та елементи:

#### 1. **Кнопка Назад** (Back)
- Повертає на попередню сторінку
- Вимикається коли немає історії назад
- Іконка: стрілка вліво

#### 2. **Кнопка Вперед** (Forward)
- Переходить на наступну сторінку в історії
- Вимикається коли немає історії вперед
- Іконка: стрілка вправо

#### 3. **Кнопка Оновити** (Reload)
- Перезавантажує поточну сторінку
- Іконка: стрілки по колу

#### 4. **Кнопка Домівка** (Home)
- Переходить на домашню сторінку (Google)
- Іконка: будинок

#### 5. **Адресна строка** (Address Bar)
- Білий фон з заокругленими краями
- Іконка безпеки (зелений щит) зліва
- Поле для введення URL або пошукового запиту
- Watermark: "Введіть URL або пошуковий запит..."
- При натисканні Enter - виконується навігація
- Автоматично визначає чи це URL чи пошуковий запит:
  - Якщо містить "." і без пробілів → додає https://
  - Інакше → пошук через Google

#### 6. **Кнопка Закладки** (Bookmark)
- Додати поточну сторінку в закладки
- Іконка: зірка (помаранчева)

#### 7. **Кнопка Tools** (Інструменти)
- Відкриває меню інструментів
- Іконка: гайковий ключ

#### 8. **Кнопка Налаштування** (Settings)
- Відкриває вікно налаштувань
- Іконка: шестерня

### Властивості контролу:
- `Url` - поточний URL
- `CanGoBack` - чи можна йти назад
- `CanGoForward` - чи можна йти вперед
- `IsSecure` - чи з'єднання безпечне

### Події (тільки для зовнішньої обробки):
- `BookmarkRequested` - натиснуто кнопку Закладки (потребує реалізації в головному вікні)
- `ToolsRequested` - натиснуто кнопку Tools (потребує реалізації в головному вікні)
- `SettingsRequested` - натиснуто кнопку Налаштування (потребує реалізації в головному вікні)

**Примітка:** Вся навігація (назад, вперед, оновити, додому, URL) обробляється **внутрішньо** контролом через `WebViewManager`.

### Дизайн:
- Висота: 36px
- Всі кнопки: 32x32px з заокругленими краями (6px)
- Прозорий фон кнопок з білим hover ефектом
- Білі іконки на кнопках
- Адресна строка з білим фоном та рамкою
- При фокусі на адресній строці - фіолетова рамка

### Інтеграція з MainWindow:
Тепер інтеграція **максимально спрощена**:

```csharp
// 1. Ініціалізація WebViewManager
_webViewManager.Initialize(webView);

// 2. Передача WebViewManager в NavigationBar
var navigationBar = this.FindControl<NavigationBar>("NavigationBar");
navigationBar.Initialize(_webViewManager);

// 3. Підписка ТІЛЬКИ на події зовнішньої обробки
navigationBar.BookmarkRequested += OnBookmarkRequested;
navigationBar.ToolsRequested += OnToolsRequested;
navigationBar.SettingsRequested += OnSettingsRequested;
```

**Переваги:**
- ✅ Код MainWindow зменшився більш ніж на 50 рядків
- ✅ Вся логіка навігації інкапсульована в NavigationBar
- ✅ Немає проміжних обробників подій для навігації
- ✅ Пошукові запити автоматично обробляються в NavigationBar
- ✅ URL без протоколу автоматично отримує https://

### Використання:
```xml
<controls:NavigationBar x:Name="NavigationBar" />
```
