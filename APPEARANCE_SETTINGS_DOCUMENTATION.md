# Налаштування вигляду - Документація

## Огляд

Система налаштувань вигляду браузера VetaleBrowser дозволяє користувачам повністю налаштувати зовнішній вигляд браузера, включаючи вкладки, головне вікно та інші вікна.

## Архітектура

### База даних

Налаштування вигляду зберігаються в окремій базі даних з AES шифруванням:
- **Файл бази даних**: `appearance_settings.db`
- **Розташування**: У тій же директорії, що й основна база даних
- **Шифрування**: AES-256 через `DatabaseEncryptionService`
- **База даних**: LiteDB з індексацією по ключу

### Сервіси

#### IAppearanceSettingsService
Інтерфейс для роботи з налаштуваннями вигляду:
- Методи для налаштувань вкладок
- Методи для налаштувань головного вікна
- Методи для налаштувань інших вікон

#### AppearanceSettingsService
Реалізація сервісу з наступними функціями:
- Збереження та отримання налаштувань з шифруванням
- Значення за замовчуванням для всіх параметрів
- Асинхронні операції з базою даних

### Сторінки налаштувань

1. **AppearanceMainPage** - Головна сторінка з розділами:
   - Вкладки
   - Головне вікно
   - Інші вікна

2. **TabAppearanceSettingsPage** - Налаштування вкладок:
   - Ширина вкладки
   - Розмір тексту
   - Розмір іконки
   - Колір фону вкладки
   - Колір тексту вкладки
   - Колір активної вкладки

3. **MainWindowAppearanceSettingsPage** - Налаштування головного вікна:
   - Колір навігаційного бару
   - Висота навігаційного бару
   - Ширина головного вікна
   - Висота головного вікна
   - Колір фону верхньої лінії
   - Розмір кнопок
   - Розмір зображень всередині кнопок

4. **OtherWindowsAppearanceSettingsPage** - Налаштування інших вікон:
   - Колір фону вікон
   - Колір верхньої панелі

## Використання

### Доступ до налаштувань вигляду

```csharp
// Ініціалізація сервісу
var appearanceDbPath = Path.Combine(dbDirectory, "appearance_settings.db");
var appearanceService = new AppearanceSettingsService(appearanceDbPath, encryptionKey);

// Отримання налаштування
var tabWidth = await appearanceService.GetTabWidthAsync();

// Збереження налаштування
await appearanceService.SetTabWidthAsync(250.0);
```

### Навігація в вікні налаштувань

Вікно налаштувань (`SettingsWindow`) автоматично керує навігацією між сторінками:

1. Користувач відкриває Settings → Appearance
2. Відображається AppearanceMainPage з трьома розділами
3. Натискання на розділ відкриває відповідну сторінку
4. Кнопка "Назад" повертає до AppearanceMainPage
5. Кнопка "Зберегти налаштування" зберігає всі зміни

### Автоматичне зміна розміру вікна

Вікно налаштувань автоматично змінює розмір залежно від сторінки:
- Головна сторінка: 660x500 px

## Безпека

Всі налаштування зберігаються з AES-256 шифруванням для захисту конфіденційності користувача. Ключ шифрування генерується автоматично при першому запуску браузера.

## Інтеграція з SettingsWindow

SettingsWindow автоматично ініціалізує сервіс налаштувань вигляду при запуску:

```csharp
private void InitializeSettingsService()
{
    var config = DatabaseConfiguration.CreateDefault();
    _settingsService = new SettingsService(config.DatabasePath, config.EncryptionKey);
    
    // Окрема база даних для налаштувань вигляду
    var appearanceDbPath = Path.Combine(
        Path.GetDirectoryName(config.DatabasePath) ?? "",
        "appearance_settings.db"
    );
    _appearanceSettingsService = new AppearanceSettingsService(appearanceDbPath, config.EncryptionKey);
}
```
